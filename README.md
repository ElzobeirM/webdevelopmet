
# KD Academy User Manual

KD Academy is a comprehensive e-learning platform designed to streamline academic processes such as course registration, attendance management, and grading. This user manual provides a step-by-step guide to assist students, lecturers, and administrators in using the system efficiently.

## Introduction

KD Academy provides a seamless experience for managing academic tasks and facilitates easy communication between students, lecturers, and administrators. This guide explains how to use the platform effectively.

## Admin Guide

Admins play a crucial role in managing the KD Academy platform. Below are the key functionalities available to administrators:

### Creating User Accounts
1. Navigate to the "User" tab in the admin dashboard.
2. Select "Create User" and fill in the necessary details, such as name, email, and role (student or lecturer).
3. Click "Save" to generate login credentials for the user.

### Managing Courses
1. Go to the "Course Management" section.
2. Add a new course by providing the course name, description, and schedule.
3. Edit or delete existing courses as needed.

### Administrative Actions
- Generate reports on attendance, grades, and course participation.
- Reset user passwords when requested.
- Determine privileges for each user.

## Student Guide

### Login Manual
1. Open the KD Academy Login using the localhost:
   ```
   http://localhost/kd_academy/login.php
   ```
2. Log in with the username and password provided by the Admin team.

### Course Enrollments
1. Select the 'Courses' tab on the navigation bar.
2. Click the 'Enroll Now' button for the desired course.
3. After enrolling, check your courses in the 'My Enrollments' tab.

### Changing the Password
1. Click the 'Change Password' button in the navigation bar.
2. Enter the current password (default is 'password'), new password, and confirm the new password.
3. Click 'Change Password' to save the changes.

### Logout
To logout, click the 'Logout' button located on the top-right side of the navigation bar.

## Lecturer Guide

### Login Manual
1. Open the KD Academy Login using the localhost:
   ```
   http://localhost/kd_academy/login.php
   ```
2. Log in with the username and password provided by the Admin team.

### Manage Course Enrollments
1. Click on 'Enrollments' to view students' information and approve or reject their course requests.

### Attendance Management
1. Choose the student and course, and mark the attendance as Present, Late, or Absent.
2. Click 'Mark Attendance' to record the data.

### Manage Grades
1. Select the student, assign assignment types, score, and max score.
2. Click 'Add Grade' to update the student grades.

### Changing the Password
1. Click the 'Change Password' button in the navigation bar.
2. Enter the current password, new password, and confirm it.
3. Click 'Change Password' to apply the new password.

### Logout
To logout, click the 'Logout' button located on the top-right side of the navigation bar.

## Conclusion

KD Academy offers a user-friendly and efficient platform for managing academic processes. This guide should help users navigate the system effectively, ensuring a smooth experience for students, lecturers, and administrators.

Happy Learning!
